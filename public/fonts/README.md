# Template display fonts

Self-hosted Latin subsets, downloaded from Google Fonts. Spanish punctuation and accented characters are included. Font display uses `swap`.

- `atelier-condensed.woff2`: Oswald, variable weights 400–700. Source: <https://fonts.gstatic.com/s/oswald/v57/TK3IWkUHHAIjg75cFRf3bXL8LICs1_Fv40pKlN4NNSeSASz7FmlWHYg.woff2>
- `atelier-serif.woff2`: Bree Serif, weight 400. Source: <https://fonts.gstatic.com/s/breeserif/v18/4UaHrEJCrhhnVA3DgluA96rp5w.woff2>

Both are distributed under the SIL Open Font License 1.1. Their original notices are preserved in `oswald-OFL.txt` and `breeserif-OFL.txt`, sourced from the Google Fonts repository (`ofl/oswald` and `ofl/breeserif`). The internal CSS aliases do not modify the font files.
