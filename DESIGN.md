# Design system

## Visual world

Menu Templates uses a premium wayfinding system: customers follow a clear route from discovery to ordering and tracking; operators follow the next valid order action. It avoids ornamental card stacks in favor of route rails, condensed labels and decisive state markers.

## Foundations

- **Ink:** `#101828` anchors operational surfaces and high-attention moments.
- **Paper:** `#f7f8f5` keeps long reading and dense operational data calm.
- **Signal:** `#ff5a1f` is reserved for primary route actions and active attention.
- **Line:** `#d7dcd5` defines quiet boundaries and navigation rails.
- **Type:** Archivo provides compact, high-legibility hierarchy; numeric data uses tabular figures.

## Components

- Public category navigation is a horizontal route rail with direct anchors.
- The cart is a dark, mobile-safe command dock; its primary action is signal orange.
- Admin operations use an ink masthead and a restrained data surface, keeping state/action scanable under service pressure.
- Focus, selection, scrollbars and browser controls inherit the same system.

## Responsive behavior

Public category rails scroll horizontally rather than wrap into unreadable controls. The cart remains within mobile safe margins. Admin content uses a single reading column on narrow screens and preserves actionable controls.

## Accessibility

Signal color is never the only state cue. Focus rings are visible, controls keep native semantics and status data remains text-readable.
